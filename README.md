# party.runeco.de

Create a party for pf2e and balance out your strengths. Likely can be supported for other games too in the future.
This is a sub project. Check out [runeco.de](https://github.com/github-reneon/runeco.de) for the full project.

## Party

You love to party. I love to party. We all love to party. Party.runeco.de allows you to organise your pf2e parties.
API calls will return Races, classes, and Archetypes for people to register characters with.
