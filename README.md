# party.runeco.de

Create a party for pf2e and balance out your strengths. Likely can be supported for other games too in the future.
This is a sub project. Check out [runeco.de](https://github.com/github-reneon/runeco.de) for the full project.

## Party

You love to party. I love to party. We all love to party. Party.runeco.de allows you to organise your pf2e parties.
API calls will return Races, classes, and Archetypes for people to register characters with.

## Getting Started

This project is built with PHP and uses [Tailwind CSS](https://tailwindcss.com/) for styling, as well as [htmx](https://htmx.org/) for dynamic, interactive user interfaces.

### Requirements

- PHP 8.1 or higher
- Composer
- Node.js & npm (for Tailwind CSS)

### Installation

1. Clone the repository:

  ```bash
  git clone https://github.com/yourusername/party.runeco.de.git
  cd party.runeco.de
  ```

2. Install frontend dependencies and build Tailwind CSS:

  ```bash
  npm install
  npm run build
  ```

3. Configure your environment variables as needed (e.g., `.env`).

4. Start your local development server:

  ```bash
  php -S localhost:8080 -t public
  ```
